Slouch Goblin 0.1.4 for Apple Silicon Macs running macOS 13 Ventura or later.

## What's new

- A **Recalibrate** button now sits above **Not hunching** when the screen
  blurs, for when your setup has changed and alerts keep firing.
- The blur and goblin fade out when you sit up instead of vanishing, and setup
  and calibration move more smoothly. Reduce Motion is respected.
- **Report an issue** opens a form already filled in with your app and macOS
  versions and the last error, so reports are quicker to write. No camera
  images or posture data are included.
- Slouch Goblin keeps a local log file. **Diagnostics…** has a **Show log**
  button if you're asked for it in an issue. The log never leaves your Mac.
- **I'm slouching** is no longer in the menu bar menu; it's still on the video
  window.

## Install

Download the `.dmg`, open it, and drag Slouch Goblin to Applications, replacing
the old copy if asked. Then open it from Applications.

This build is signed and notarized by Apple, so it opens without any security
warning.

## Verifying your download

```bash
shasum -a 256 -c Slouch-Goblin-0.1.4-arm64.dmg.sha256
```
