Slouch Goblin 0.1.2 for Apple Silicon Macs running macOS 13 Ventura or later.

## What's new

- Signed with an Apple Developer ID and notarized by Apple again, so it opens
  normally. You no longer have to click **Open Anyway** in System Settings.
- Fixed a crash after about an hour of monitoring. GPU pose detection was
  leaking memory on every frame until the app quit.
- The **Not slouching** button now matches the rest of the app and sits
  centered near the bottom of every display.

## Updating from 0.1.1

0.1.1 was a self-signed build. Because 0.1.2 is signed differently, macOS
treats it as a new app the first time it opens:

- Allow camera access again when macOS asks.
- If you used **Open at login**, turn it back on from the menu.

You only do this once. Later updates keep both settings.

## Install

Download the `.dmg`, open it, and drag Slouch Goblin to Applications, replacing
the old copy if asked. Then open it from Applications and allow camera access
when macOS asks.

## Verifying your download

```bash
shasum -a 256 -c Slouch-Goblin-0.1.2-arm64.dmg.sha256
```
